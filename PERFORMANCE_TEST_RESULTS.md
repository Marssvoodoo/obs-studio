## How to Re-run the Benchmarks

```powershell
# From the project root, run the automated scenario suite:
cd "c:\OBS Project\tools"

# All four scenarios, 10 min each (skip to jump over any):
.\obs-run-scenarios.ps1

# Single scenario, custom duration:
.\obs-perf-monitor.ps1 -ScenarioName "Test1_SingleSource_Baseline" -DurationSeconds 600

# Quick spot-check (60 seconds):
.\obs-perf-monitor.ps1 -ScenarioName "QuickCheck" -DurationSeconds 60
```

CSVs and the auto-generated `SUMMARY_*.csv` are written to `tools\results\`.
